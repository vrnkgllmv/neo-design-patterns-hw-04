# HW 04: Creational Patterns (Singleton, Builder, Prototype)

Цей проєкт демонструє використання породжувальних патернів проєктування (Singleton, Builder, Prototype) на прикладах з практичного TypeScript-контексту.

## Структура проєкту

* `/src/singleton` - реалізація патерну Одинак (`AppConfigService`), який зберігає глобальні налаштування для всього застосунку.
* `/src/builder` - реалізація патерну Будівельник (`DocumentBuilder`), який централізує логіку формування документа (заголовок, тіло, підпис).
* `/src/prototype` - реалізація патерну Прототип (`UserProfile`, `UserProfilePrototype`), що дозволяє створювати незалежні копії профілів користувачів із глибоким клонуванням прав доступу.

## Використані патерни

* **Singleton**: гарантує, що у всій системі існує лише один екземпляр класу (`AppConfigService`), та надає глобальну точку доступу до нього.
* **Builder**: дозволяє створювати складні об'єкти крок за кроком (наприклад, текстовий документ), ізолюючи логіку побудови від їхнього представлення та зберігаючи правильний порядок частин.
* **Prototype**: дозволяє створювати точні копії існуючих об'єктів (`UserProfile`), не покладаючись на їхні класи, за допомогою методу `clone()` з глибоким копіюванням вкладених полів.

## Інструкція із запуску

Встановіть залежності (якщо ще не встановлено):

```bash
npm install
```

Запустіть відповідний скрипт для перевірки конкретного патерну:

**Singleton:**
```bash
npx ts-node src/singleton/main.ts
```

**Builder:**
```bash
npx ts-node src/builder/main.ts
```

**Prototype:**
```bash
npx ts-node src/prototype/main.ts
```
